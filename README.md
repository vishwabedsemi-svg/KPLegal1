# KP Legal — Premium Website Template

A responsive, editorial-style landing page for an Ontario paralegal services business. Built with HTML and CSS, with a small inline script for the mobile navigation and current year.

## Files
- `index.html` — page structure, navigation, service sections, FAQ, contact form, legal notice.
- `styles.css` — design system, responsive layouts, hover/focus states, reduced-motion support.

## Preview locally
Open `index.html` in a browser. Google Fonts and Unsplash photos load from the internet.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and this README to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select your main branch and `/ (root)`, then save.
4. Wait for the deployment and open the URL GitHub Pages provides.

## Before publishing — important
- **Brand:** “KP Legal” is a placeholder. Replace the business name, logo/brand language, email, and all contact details with verified information.
- **Legal scope:** Verify the services shown against the paralegal's licence and the Law Society of Ontario's current rules. Remove any service that is outside the licensee's authorized scope or competence.
- **Contact form:** The form uses FormSubmit as a demo endpoint. Replace `hello@kplegal.ca` in the form `action` and visible email with a verified inbox, then test the verification/delivery flow and privacy implications. For a production site, consider a form provider with appropriate privacy/security controls. Do not collect confidential details in an initial web form.
- **Privacy and accessibility:** Publish a privacy notice that fits your actual data handling, review consent wording, test keyboard/mobile behaviour, and add any required business disclosures.
- **Images and fonts:** Images are remotely hosted on Unsplash and fonts on Google Fonts. Replace with licensed, brand-appropriate assets if desired.
- **No legal advice:** This template is a design starter, not legal advice or a compliance review. It does not create a paralegal-client relationship, and it makes no promises about outcomes.
